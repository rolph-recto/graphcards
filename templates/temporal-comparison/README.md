# Temporal comparison

This template demonstrates a `temporal_comparison` generator. The ordered member list supplies
the 1-based position for each event. Each event receives a card that compares it with a different
event from the same group.

The front asks whether the target happened before or after the comparison event. The back contains
the answer. The `event_label` slot selects the displayed target and comparison names. JSON, TOML,
and YAML decks use the same exercise configuration.
